Imtan (อิ่มทัน)

Canteen queue web app · Exploring Engineering World, Chulalongkorn University

A working prototype for the Engineering canteen. Students see every shop's live queue, order ahead, get a queue number with a live wait estimate, and an alert when the food is ready. Vendors run a live order board on a tablet. Payment is a built-in demo.

TypeScript Next.js Supabase PostgreSQL

Kit2Code Grader

Practice grader for old contest problems · Kit2Code

Students read a problem in Thai or English, submit C, C++ or Python, and watch the result arrive per test and per subtask, scored the way CMS v1.5 scored the original contest. Submissions run in the isolate sandbox, on the same home server as our CMS, without the two sandboxes ever touching.

Early development: sign-in, problems, live results, ranking and the admin site work today

Python Django PostgreSQL Docker

CMS Admin Helper

Chrome & Firefox Extension

Adds the contest-day tools the CMS v1.5 admin is missing: a contestant tracker, bulk import from Excel or Google Sheets, and Bangkok-time scheduling. It drives the admin's own forms, so the server needs no changes.

Load-tested on AWS: 2,000 submissions + a 300-user import, median 171 ms, p95 under 650 ms

TypeScript Browser Extension

TaskMaker

Authors write olympiad problems in YAML, validated against a schema. The live preview and the PDF export share one template, so what you see is exactly what prints, with Thai typography and KaTeX math built in.
