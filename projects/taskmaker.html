TaskMaker

A problem studio for contest authors: write an olympiad problem in YAML, see it rendered, print the same thing as a PDF.

Code ›

Why I built it

Kit2Code contests are written in Thai and judged on Codeforces or our own CMS. Each problem needs a statement that looks right on screen and in the printed packet, with Thai text and math in the same page. Before TaskMaker, statements were written in Word. Compiling those documents into a finished packet, with the fonts, images and everything else in place, was hard.

What it had to do

  • Thai typography and KaTeX math both have to print correctly.
  • What an author sees in the preview has to be exactly what prints.

What I chose

  • One template for preview and PDF. The live preview and the PDF export share a single template, so the two cannot drift apart.
  • YAML, validated against a schema. Authors write problems as plain text in a fixed structure.
  • Docker and PostgreSQL. I already run a home server, so TaskMaker runs there in Docker with PostgreSQL behind it.

How it went

I used it to write the problems for Kit2Code's contests: 2 contests, 11 original problems so far.
